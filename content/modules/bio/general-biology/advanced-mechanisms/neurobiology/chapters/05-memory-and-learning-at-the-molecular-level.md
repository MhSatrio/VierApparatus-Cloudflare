Memory is stored in the brain through changes in the strength of synapses and in the connections among neurons. Short-term memory lasts minutes and depends on changes in the modification of existing proteins, such as the phosphorylation that strengthens synapses for a short time. Long-term memory lasts days to years and requires the synthesis of new proteins and, in some cases, new structural connections. The transition from short- to long-term memory is called consolidation.

Protein synthesis is needed for consolidation. Inhibitors of translation or transcription given during the learning period prevent long-term memory from forming, while short-term memory is spared. The new proteins are needed to stabilise the structural changes that accompany potentiation, and the transcription of genes in the nucleus is needed to produce them. The requirement shows that memory involves gene expression as well as synaptic modification.

Jenuwein and Allis (2001) described how histone modifications regulate gene expression, and there is evidence that changes in histone acetylation accompany learning and that manipulating these marks alters memory formation. The epigenetic changes described in the Advanced Epigenetics module provide one way that experience can produce lasting changes in gene activity.

The idea that molecules store information is strongly supported in some contexts and less so in others. The persistence of a memory cannot be attributed to a single molecule, because proteins turn over within days, and the memory must be maintained by networks of molecules that reinforce one another. Some molecules, such as the self-sustaining kinases described in the previous chapter, provide a candidate for this maintenance.

Ioannidis (2005) described the difficulty of establishing causal links in a field with many claims, and the molecular basis of memory has produced results that have not always replicated. Strong evidence requires that a molecular manipulation alters a defined memory without affecting other functions, and that the effect is reproduced in independent experiments.

Alberts et al. (2022) describe the gene expression and protein synthesis machinery whose role in memory is studied. Memory is studied in behavioural paradigms combined with pharmacological and genetic manipulation, and by measuring the molecular changes that accompany learning.
