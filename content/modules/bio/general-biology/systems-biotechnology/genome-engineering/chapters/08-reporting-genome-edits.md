A genome edit can be reproduced only if the report states exactly what was done to the genome. The target sequence, the guide with its protospacer adjacent motif, and the nuclease used should be given first. If a donor template was supplied, its sequence and the lengths of its arms should be stated, since these determine the outcome of repair. Peng (2011) argued that a result is reproducible only with the means of producing it, and for an edit the means are the sequences and the reagents.

The cells and clones should be described by their genotypes. The number of cells treated, the number of clones isolated and the number verified with each genotype should be reported, since the phenotype of an edit is interpreted through them. Sandve et al. (2013) recommended keeping the inputs, steps and outputs of an analysis together, and in genome engineering the inputs include the clone history and the verification.

The verification and the off-target analysis should be reported with their methods and sensitivities. Cumming (2014) argues that frequencies should be given with their intervals, and a claim that no off-target cut occurred must state the sensitivity of the method used to look for it. Ioannidis (2005) described how a null finding from an insensitive method can be mistaken for an absence, so the detection limits should be shown.

The phenotype should be reported with the controls and the number of independent clones, so that its link to the edit can be judged. The sequences, the sequencing reads and the protocol should be deposited with identifiers, so that the edit can be checked and repeated by others.
