The ribosome adds amino acids in the order given by the messenger RNA, and the messenger is read in groups of three bases. Each group of three is a codon, and each codon specifies either an amino acid or a stop signal. The set of rules that links codons to amino acids is the genetic code. This chapter describes how the code was deciphered and why it works the way it does.

With four bases and groups of three, there are sixty-four possible codons. Sixty-one of them specify one of the twenty amino acids, and three stop the chain. Because there are more codons than amino acids, most amino acids have several codons. Methionine, for example, has one codon, while leucine has six. This feature is called redundancy, and it makes the code robust to some changes in the message.

Nirenberg and Matthaei (1961) carried out an experiment that helped reveal the code. They added synthetic RNA made of a single repeating base to a cell-free system that could make protein. When they used RNA made only of uracil, the system made a chain built from phenylalanine. This result connected a particular codon to a particular amino acid, and it started the process of deciphering the rest of the code.

The experiments that followed used other synthetic messages, with mixtures of bases in known proportions, to assign more codons. Over the next years, researchers worked out which codon matched which amino acid, and the full code was established. The work showed that the code is nearly universal, with the same assignments used in almost every organism.

Steitz (2008) described how the ribosome reads codons. The small subunit positions the messenger RNA and checks the match between each codon and the anticodon of the incoming transfer RNA. The ribosome therefore uses the code as a set of instructions that it follows in each cycle.

Pauling, Corey and Branson (1951) described the peptide chain that the code builds. The code specifies the order of amino acids, and the regular backbone of the chain is the framework on which those amino acids are placed. The code and the backbone work together to produce a protein.

The reading of the code begins at a start codon, usually AUG, which also specifies methionine. The ribosome reads from that point, codon by codon, until it reaches a stop codon. The reading frame is set by the start, and a change in the frame would alter every codon that follows.

Students should note that the code is redundant but not random. Codons that specify the same amino acid are often similar in their first two bases, and changes in the third base are more likely to leave the amino acid unchanged. This pattern makes the code less vulnerable to damage, because many changes are silent.

A helpful picture is a dictionary in which each word is three letters long and many different spellings lead to the same meaning. The reader scans the message three letters at a time, looks up each word and adds the matching meaning to the text. The dictionary is the genetic code, and the reader is the ribosome.

The code also explains why some mutations change a protein and others do not. A change in the third base of a codon often leaves the amino acid the same, while a change in the first or second base often replaces it. Knowing the code allows scientists to predict whether a change in a gene will alter the protein it makes, which is an important step in understanding disease.

Students can practice reading the code by taking a short messenger RNA sequence, cutting it into codons and looking up each one in a table of the code. The exercise makes the reading frame concrete and shows how a single added or missing base can shift every codon that follows.

To summarize, the genetic code reads the messenger RNA in codons of three bases, with sixty-one codons specifying amino acids and three acting as stops. Nirenberg and Matthaei's experiments began the decipherment, and the code is redundant and nearly universal. The next chapter describes the errors that can affect peptide bond formation.
